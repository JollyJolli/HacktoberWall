04 / ContributeOpen source

Put your name on the wall.

Add one JSON file for your profile, or help shape the 2026 page itself. That is the whole point.

  1. Fork the repo.
  2. Copy 2026/data/contributors/_template.json.
  3. Rename it to your GitHub username.
  4. Open a pull request.
